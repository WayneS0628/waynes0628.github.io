# waynesimmonsjr.com

Personal site of Wayne Simmons. Built with [Astro](https://astro.build), deployed to GitHub Pages by GitHub Actions.

- `npm run dev`: local dev server
- `npm run build`: production build into `dist/` (fails on em dashes in copy)
- `npm run todos`: list every `TODO: Wayne` placeholder
- `npm run map`: recompute the homepage project map (embeddings + PCA)

How to add projects, posts, and photos (in code or with the web editor): [EDITING.md](EDITING.md).

The previous Jekyll version of the site is preserved at the `jekyll-final` tag.
